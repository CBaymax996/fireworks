# Plan: Fix fireworksRun to run frontend and backend in parallel

## Problem
`bootRun` is a long-running task that never completes, so `finalizedBy("npmRunDev")` never executes. Only the backend starts.

## Solution
Replace the `dependsOn`/`finalizedBy` approach with a custom task that uses `ProcessBuilder` to start both backend and frontend in parallel. The task will:
- Block until one process exits
- Register a shutdown hook to kill all processes when the task is cancelled (Ctrl+C or IntelliJ stop)
- Properly handle process lifecycle

## File to modify
- `/Users/chuhao.16/Projects/fireworks/build.gradle.kts`

## Implementation

Replace lines 24-52 (fireworksRun and npmRunDev tasks) with a single `fireworksRun` task:

```kotlin
tasks.register("fireworksRun") {
    description = "启动 Fireworks 应用。用法: ./gradlew fireworksRun -Penv=dev|prod (默认 prod)"
    group = "application"

    doLast {
        println("fireworks run. env: $env")

        val processes = mutableListOf<Process>()
        val shutdownHook = Thread {
            processes.forEach { if (it.isAlive) it.destroyForcibly() }
        }
        Runtime.getRuntime().addShutdownHook(shutdownHook)

        try {
            if (env == "dev") {
                // 启动后端
                val backend = ProcessBuilder(
                    "./gradlew", ":fireworks-server:bootRun"
                ).apply {
                    inheritIO()
                    environment("SPRING_PROFILES_ACTIVE", "dev")
                }.start()
                processes.add(backend)

                // 启动前端
                val frontend = ProcessBuilder("npm", "run", "dev")
                    .directory(file("fireworks-web"))
                    .inheritIO()
                    .start()
                processes.add(frontend)

                // 等待任一进程退出
                processes.forEach { it.waitFor() }
            } else {
                // prod: 打包后端
                ProcessBuilder("./gradlew", ":fireworks-server:bootJar")
                    .inheritIO().start().waitFor()

                // prod: 打包前端
                ProcessBuilder("npm", "run", "build")
                    .directory(file("fireworks-web"))
                    .inheritIO().start().waitFor()
            }
        } finally {
            processes.forEach { if (it.isAlive) it.destroyForcibly() }
            Runtime.getRuntime().removeShutdownHook(shutdownHook)
        }
    }
}
```

## Key behaviors
- **Dev mode**: Starts both backend and frontend, blocks until one exits
- **Prod mode**: Runs sequentially (backend build, then frontend build)
- **Cancellation**: Ctrl+C or IntelliJ stop button triggers shutdown hook, kills all child processes
- **IntelliJ integration**: Task appears in "Application" group, can be started/stopped from IDE
